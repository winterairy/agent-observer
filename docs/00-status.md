## 단계 판단 이유
- 기획: 새 기능, HANDOFF의 1단계 항목에 수용 기준이 없음
- 설계: 새 API·저장소 인터페이스·데이터 모델·새 라이브러리(Next.js 등)
- 디자인 명세: 새 화면, 디자인 기준 문서 없음
- 보안: 토큰 인증, 로그인, 외부 입력(payload) 파싱, 의존성 추가
- 운영: 신규 프로젝트, 환경 변수(OBSERVER_TOKEN, 로그인 비밀번호). 실제 배포는 하지 않음

## 결정 사항
- 승인1 (2026-11-11): D-1~D-20 기본값 채택(D-6은 승인 대기 예외 반영)
- 로그인한 사용자만 모든 기능 사용. 캐릭터 설정·그림도 로그인 필요, public/ 사용 안 함
- 서버 OBSERVER_TOKEN이 없거나 16자 미만이면 오류 메시지(server_token_invalid)와 함께 401
- command 필드 저장: command_name만 오고 인자는 오지 않음을 확인. 원본 이벤트에만 저장
- 문서 불일치 8건 정리
- 디자인 (2026-11-11): 색 v3 승인(크림·남색 잉크·테라코타), 다크 모드에서도 사무실은 밝은 색 유지, Pretendard 웹폰트 사용, 로그인 화면 비밀번호 안내 각주
- 숨긴 세션 보기·다시 표시를 1단계에 포함
- 사무실 방향: Pixel Agent Desk의 사무실 구조(좌석·상태별 동작·레이어)를 살리고, 그림은 GBA 시절 탑다운 RPG 실내풍으로 새로 그린다(원본 그림·기존 게임 그림은 쓰지 않음)
- 승인 대기는 시간이 지나도 종료하지 않고 기다린 시간 표시, 24시간 넘으면 "응답 없음" 표시, 사용자가 "정리"로 숨김. 휴대폰 푸시 알림은 2단계 (사용자 결정, 2026-11-11)
- 비용은 "API 환산 비용"으로 표시하고 실제 청구액이 아님을 안내한다 (사용자 결정, 2026-11-11)
