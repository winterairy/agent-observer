# agent-observer

Claude Code 세션과 [dev-team-kit](https://github.com/winterairy/dev-team-kit) BOT의 활동, 토큰 사용량, 스킬 사용을 픽셀 사무실 화면으로 보는 관찰 서버입니다.

상태: 준비 단계. 결정 사항과 1단계 범위는 [docs/HANDOFF.md](docs/HANDOFF.md)에 있습니다.

이 저장소에는 dev-team-kit이 설치되어 있습니다. Claude Code에서 `/team-init`으로 설정을 만든 뒤 `/task`로 진행합니다.

참고한 외부 코드는 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)를 보세요.
